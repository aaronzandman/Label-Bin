How printing works
  1. Print batch opens your browser's print window with the batch as plain ZPL text.
  2. Pick the printer named Zebra ZPL (the Generic / Text Only printer on the Zebra's USB port, see the setup guide).
  3. Under More settings: turn off Headers and footers and set Margins to None. The browser remembers these.
  4. Click Print. The text goes to the Zebra unchanged, and the Zebra turns it into labels.

If that ever prints garbled labels, use Download .zpl, open the file in Notepad, and print it to Zebra ZPL.
